## Requirements:
- Exist a `\data` directory that contains a .parquet file of the dataset (currently only support `formatid: gen9ou`), `moves.json` file that contains all moves data, `pokedex.json` file that contains basic pokemon's data. All of the resources can be downloaded via these link:
[https://huggingface.co/datasets/HolidayOugi/pokemon-showdown-replays/blob/main/%5BGen%209%5D%20OU_part1.parquet?sql_row=2]
[https://play.pokemonshowdown.com/data/moves.json]
[https://play.pokemonshowdown.com/data/pokedex.json]
